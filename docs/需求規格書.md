# 需求規格書：台股選股網站（v1）

> 本文件是三層訪談的完整記錄（2026-10-04）。**狀態：已確認（2026-10-04）**，為開發依據。
> 標記 **〔Claude 決定〕** 的項目，是使用者授權由 Claude 以「專業投資者＋一般投資者」雙重視角決定的部分，請特別過目。

---

## 一、核心框架（Why & What）

| 項目 | 內容 |
|---|---|
| 核心目標 | 做一個功能完整的台股選股網站，同時滿足一般投資者（好上手）與專業投資者（條件夠細、可回測）的需求 |
| 最終預期產出 | 可上線使用的網站（電腦＋手機），含：基本面／技術面／籌碼面篩選、預設策略名單（含大師策略）、回測、個股詳情頁、自選股、管理後台 |
| 主要使用對象 | 第一階段：Willy 邀請的朋友（邀請制，預估 ≤ 50 人）；架構預留之後開放大眾的空間 |
| 商業模式 | 不收費，純工具 |
| 市場範圍 | 台股：上市＋上櫃普通股＋ETF（不含興櫃） |

### 要解決的痛點〔Claude 整理，使用者同意方向〕

- **一般投資者**：工具太專業看不懂、不知道條件怎麼設、資料散在 Goodinfo／財報狗／券商 App 好幾個地方
- **專業投資者**：免費工具條件不夠細、無法組合複雜條件、沒有回測、進階功能要付費

### 成功標準〔Claude 決定〕

1. 每個交易日收盤後資料自動更新，**22:30 前**全部完成
2. 從首頁開始，**3 次點擊內**拿到一份篩選名單（首頁 → 策略卡 → 結果）
3. 篩選結果 **1 秒內**出現；3 年回測 **5 秒內**跑完（一般手機也一樣）
4. 每月營運成本 **≤ NT$300**（目標 NT$0）
5. 手機、電腦都能順暢操作，不需要放大或橫向捲動

## 二、執行細節（How & Rules）

### 2.1 功能範圍（v1 六大塊全做）

#### A. 篩選條件庫

| 類別 | 條件 |
|---|---|
| 基本面 | 本益比、股價淨值比、現金殖利率、股價營收比（PSR）、市值、EPS（單季／近四季）、EPS 年增率、月營收月增／年增率、營收連續 N 月年增、毛利率／營益率／淨利率、ROE、ROA、負債比、流動比率、自由現金流、連續配息年數 |
| 技術面 | 均線（5／10／20／60／120／240 日）、均線多頭／空頭排列、KD(9)、MACD(12,26,9)、RSI(14)、布林通道(20,2)、量比（當日量 ÷ 20 日均量）、距 52 週高點／低點、N 日漲跌幅、創 N 日新高／新低 |
| 籌碼面 | 外資／投信／自營商買賣超（張數、連續天數、N 日累計）、外資持股比率、融資餘額增減、融券餘額、券資比 |

- 條件之間用 **AND** 組合（v1）；每個條件旁顯示「單獨符合幾檔」，方便找出過嚴的條件
- 可存成「我的策略」（需登入）

#### B. 預設策略名單（共 14 套）〔Claude 決定〕

所有數字都是**預設值，使用者可在網站上調整**。超過持股上限時，依「排序」欄取前段。

**基本策略（5 套）**

| 策略 | 預設條件 | 排序 |
|---|---|---|
| 存股 | 現金殖利率 ≥ 5%、連續配息 ≥ 5 年、近四季 EPS > 0 | 殖利率高→低 |
| 價值 | 本益比 < 12、股價淨值比 < 1.5、近四季 EPS > 0 | 本益比低→高 |
| 成長 | 月營收年增率 > 20% 連續 3 個月、最近一季 EPS 年增 > 0 | 營收年增率高→低 |
| 動能 | 收盤 > 5MA > 20MA > 60MA、量比 ≥ 2、收盤創 20 日新高 | 量比高→低 |
| 籌碼 | 投信連續買超 ≥ 3 日、外資近 5 日合計買超 > 0 | 投信連買天數多→少 |

**大師策略（9 套）**：依公開著作整理的台股量化近似版，頁面註明「非原作者背書」

| 策略 | 預設條件 | 排序 |
|---|---|---|
| 葛拉漢・防禦型投資人 | 排除金融股；市值前 30%；流動比率 > 2；近 5 年每年 EPS > 0；連續配息 ≥ 5 年；近 3 年平均 EPS ≥ 前 3 年平均 × 1.33；本益比 × 股價淨值比 < 22.5 | 本益比×淨值比 低→高 |
| 巴菲特風格・品質護城河 | 近 5 年 ROE 每年 > 15%；負債比 < 50%；近 3 年自由現金流皆 > 0；近 5 年毛利率最低值 ≥ 最高值的 80%（穩定）；本益比 < 25 | ROE 高→低 |
| 葛林布雷・神奇公式 | 排除金融、公用事業；市值 ≥ 50 億；盈餘殖利率（EBIT ÷ 企業價值）與資本報酬率（EBIT ÷（淨營運資金＋淨固定資產））各自排名後相加 | 綜合排名 佳→差 |
| 彼得林區・PEG | PEG（本益比 ÷ 近 3 年 EPS 年均成長率%）< 1；EPS 成長率 10%–50%（排除異常值）；負債比 < 50% | PEG 低→高 |
| 歐尼爾・CAN SLIM | C：最近一季 EPS 年增 ≥ 25%；A：近 3 年年度 EPS 逐年成長；N：距 52 週高點 ≤ 15%；S：量比 ≥ 1.5；L：近 6 個月漲幅排名前 20%；I：外資或投信近 20 日合計買超；M：加權指數 > 200 日均線（不成立時頁面提示「大盤偏空，原策略建議觀望」） | 6 個月漲幅 高→低 |
| 皮爾托斯基・F-Score | 排除金融股；9 項財務健康分數 ≥ 8（ROA > 0、營業現金流 > 0、ROA 年增、營業現金流 > 淨利、長期負債比下降、流動比率上升、股數未增加、毛利率上升、資產周轉率上升）；股價淨值比位於全市場最低 20% | F-Score 高→低，再看淨值比 低→高 |
| 肯恩費雪・股價營收比 | PSR < 0.75；近一年營收年增 > 0；負債比 < 50% | PSR 低→高 |
| 約翰聶夫・低本益比總報酬 | 本益比低於全市場中位數 40% 以上；EPS 年均成長率 7%–20%；總報酬比（(EPS 成長率% + 殖利率%) ÷ 本益比）≥ 全市場中位數的 2 倍 | 總報酬比 高→低 |
| 德雷曼・逆向投資 | 本益比、股價淨值比、股價現金流比三項中，至少兩項位於全市場最低 20%；市值前 50%；流動比率 > 1.5；負債比 < 50%；殖利率 > 全市場中位數 | 本益比 低→高 |

- 每套策略頁面都有：白話說明（給一般投資者）、完整條件與公式（給專業投資者）、目前符合清單、「一鍵回測」、「以此為範本調整」

#### C. 回測〔Claude 決定〕

| 設定 | 預設值 | 可否調整 |
|---|---|---|
| 選股來源 | 任一預設策略或「我的策略」 | — |
| 回測期間 | 最近 3 年 | 可選 1／2／3 年或自訂起訖（最長 3 年） |
| 換股頻率 | 每月第一個交易日 | 每月／每季 |
| 持股上限 | 20 檔，等權重 | 5–50 檔 |
| 成交價 | 訊號日的**下一個交易日開盤價**（避免偷看未來） | — |
| 交易成本 | 手續費 0.1425%（買賣各一次）、證交稅 0.3%（ETF 0.1%）、滑價 0.1% | 手續費可設折數 |
| 股利 | 用還原股價計算，股利再投入 | — |
| 財報可用日 | 法定公布期限後才納入（Q1：5/15、Q2：8/14、Q3：11/14、年報：3/31；月營收：次月 10 日） | — |
| 倖存者偏差 | 回測股票池包含已下市股票 | — |
| 比較基準 | 發行量加權股價**報酬**指數（含息，比加權指數公平） | — |

**回測結果**：權益曲線（對比基準）、總報酬、年化報酬（CAGR）、最大回撤（MDD）、年化波動、夏普值、月勝率、逐年報酬表、每期持股清單、交易紀錄。登入使用者可存回測紀錄。

#### D. 個股詳情頁

- K 線（日／週／月），預設原始價，可切換還原價（切換時均線一起重算）
- 均線、成交量、KD、MACD
- 基本資料、月營收（12 個月以上）、季財報（EPS、三率、ROE）、股利歷史
- 三大法人買賣超、融資融券走勢
- 「目前符合哪幾套策略」標籤、加入自選股

#### E. 首頁與其他頁面

- **首頁**：資料日期、大盤概況（加權指數、漲跌家數、三大法人合計買賣超）、14 張策略快捷卡、我的自選股
- **篩選結果**：電腦版用高密度表格（可排序、可自選欄位、匯出 CSV）；手機版改成卡片列表；結果超過 100 檔時分段載入
- **自選股**：加入／移除、顯示當日漲跌與符合策略
- **管理後台**（只有 Willy）：核准或移除使用者、查看每日資料更新狀態
- **免責聲明頁**，加上每頁頁尾的短版聲明

### 2.2 登入與權限

- 用 Google 帳號登入，採**邀請制**
- 流程：朋友用 Google 登入 → 不在白名單時顯示「已送出申請，等待管理員核准」 → Willy 在後台核准 → 開通
- 登入後才能使用全站功能；每位使用者各自保存策略、自選股、回測紀錄

### 2.3 資料來源與更新

| 資料 | 來源 | 更新 |
|---|---|---|
| 日成交行情、本益比／殖利率／淨值比、三大法人、融資融券、外資持股 | 證交所、櫃買中心公開資料 | 每個交易日盤後 |
| 月營收、季財報、股利 | 每期更新：證交所／櫃買 OpenAPI；歷史回補：FinMind 免費方案（一次性）。不直接爬公開資訊觀測站（robots.txt 禁止） | 依公布時程 |
| 加權指數、報酬指數 | 證交所 | 每個交易日盤後 |

- 預定每天跑兩次：**17:30**（行情、法人、本益比）、**22:30**（融資融券補齊）。實際時間在 PoC 階段依各資料的真實公布時間調整
- **資料保存期間**〔Claude 決定〕：
  - 價量：4 年（3 年回測 ＋ 1 年指標暖身，例如 240 日均線、52 週高點）
  - 財報與股利：8 年（「連續配息 5 年」「近 5 年 ROE」「葛拉漢 6 年 EPS 比較」需要，資料量很小）
- **不做**即時報價（富邦 API 條款禁止把行情轉給他人，列入未來版本，且只限 Willy 本人使用）

### 2.4 技術架構〔Claude 決定，以「單純、免費、Claude 好維護」為原則〕

| 層 | 選擇 | 理由 |
|---|---|---|
| 網站 | Next.js，部署在 Vercel（免費方案） | 主流、文件多，Claude 好維護 |
| 登入與使用者資料 | Supabase（Google 登入、白名單、策略、自選股、回測紀錄） | 免費額度足夠，自帶登入功能 |
| 每日資料管線 | GitHub Actions 排程跑 Python | 免費、穩定，不需要自己架主機 |
| 市場資料儲存 | 預先算好的資料檔（最新快照、月底快照、個股歷史），放在物件儲存（Supabase Storage，不夠時改用 Cloudflare R2），需登入才能讀取 | 不需付費資料庫；資料只有幾 MB 到幾十 MB |
| 篩選與回測運算 | 在使用者的瀏覽器裡算（Web Worker） | 反應快、伺服器成本近乎 0；50 人以內完全夠用 |

- 各平台的免費額度，在**開發第一步（PoC）**以 2026 年當下條款重新驗證；超出預算時先回報再調整，不會自行升級付費方案
- 自訂網域（約 NT$400／年）為選配；預設使用 Vercel 提供的免費網址

### 2.5 開發順序（每一階段完成都可先使用）

0. **PoC**：驗證資料源可抓、免費額度、資料檔大小
1. **資料管線**：每日抓取＋歷史回補（價量 4 年、財報 8 年）
2. **登入／白名單＋自訂篩選＋結果頁**
3. **個股詳情頁**
4. **14 套策略名單**
5. **回測**
6. **自選股、管理後台、收尾優化**（深淺色與術語說明從第 2 階段就內建）

### 2.6 限制條件

- 預算：每月 ≤ NT$300
- 平台：網頁（RWD），不做 App
- 語言：只做繁體中文
- 維護：使用者不寫程式，全部由 Claude 開發與維護 → 程式碼要有清楚註解與 README

### 2.7 明確不做（v1 範圍外）

即時報價、下單交易、AI 推薦、收費機制、美股或其他市場、興櫃

## 三、細節中的細節（Edge Cases & 隱性偏好）

### 3.1 例外情況處理

| 情況 | 處理方式 |
|---|---|
| 資料更新失敗或延遲 | 頁首顯示「資料日期：YYYY/MM/DD」＋黃色提醒，沿用前一交易日資料（使用者選定，不另外發通知） |
| 非交易日（假日、春節） | 依證交所休市日曆，不更新也不顯示提醒 |
| 臨時休市（颱風假） | 顯示「今日可能休市或資料延遲」 |
| 新上市、資料不足 | 指標顯示「—」，該條件視為不符合；個股頁註明「上市未滿 N 日」 |
| ETF 沒有財報 | 使用基本面條件時自動排除 ETF，結果頁註明 |
| 金融股財報結構不同 | 神奇公式、葛拉漢、F-Score 自動排除金融股，策略說明中註明 |
| 除權息、減資、分割 | 篩選與回測一律用還原價；K 線預設顯示原始價 |
| 篩選結果 0 檔 | 顯示「沒有符合的股票」，並標出「單獨符合檔數最少」的條件，建議放寬 |
| 回測某期 0 檔符合 | 該期持有現金 |
| 回測中股票下市 | 以最後交易日收盤價出場 |
| 回測中暫停交易 | 沿用最後成交價，直到恢復交易或下次換股 |
| 財報重編或更正 | 以最新版本為準（會產生輕微前視偏誤，回測頁註明） |
| CAN SLIM 的 M 條件不成立 | 仍列出結果，但顯示「大盤偏空，原策略建議觀望」 |
| 非白名單帳號登入 | 顯示等待核准頁面，不顯示任何資料 |

### 3.2 隱性假設（使用者沒說，但預期要有的）〔Claude 決定〕

- 紅漲綠跌（台股習慣）
- 金額用「億／萬元」，成交量用「張」，百分比到小數第 2 位，日期格式 YYYY/MM/DD
- 數字用等寬字體，表格欄位對齊
- 每個條件、指標都有「白話說明」（點一下或滑過去就跳出來）
- 免責聲明：「本網站為資料篩選工具，所有結果僅供參考，不構成任何投資建議」
- 網站內不出現「推薦」「建議買進」「必漲」等字眼，一律用「符合條件」（降低被認定為投顧行為的風險；若之後要開放大眾，需另外評估法規）

### 3.3 用語與視覺偏好

- **喜歡**：可切換深色／淺色（預設跟隨系統設定）；電腦版資訊密度高（給專業投資者），手機版卡片式（給一般投資者）
- **參考**：深色模式參考 TradingView，淺色模式參考財報狗
- **不喜歡／禁用**〔Claude 決定〕：花俏動畫、廣告感版面、誇大用語（「飆股」「穩賺」）
- **反例**：Goodinfo 式的超長單頁、資訊全部擠在一起，手機上難以閱讀

### 3.4 模糊情況下的預設行為

- 使用者授權：遇到未定義的細節，Claude 以「專業投資者＋一般投資者」雙重視角自行決定，並記錄在 `專案上下文.md` 的決策紀錄
- 判斷原則：**正確性 > 簡單好維護 > 功能豐富**；涉及費用、法規、資料授權的決定，一律先問使用者

## 四、使用者授權由 Claude 決定的假設

- **假設一**：14 套策略的條件與預設數字，由 Claude 依公開資料整理，使用者可在網站上調整
- **假設二**：回測規則（下一日開盤成交、含成本、還原價、含下市股、報酬指數作為基準）以專業回測標準設定
- **假設三**：資料保存「價量 4 年／財報 8 年」，比訪談中說的 3 年多，原因是指標暖身與長期財報條件需要；回測期間仍維持最長 3 年
- **⚠️ 高風險假設（猜錯需大改）**：技術架構採用「預先算好的資料檔 ＋ 瀏覽器端運算」。好處是 50 人以內幾乎零成本；代價是**之後如果真的要開放給大眾**（上千人、要擋爬蟲、要做即時報價），市場資料層需要改成伺服器端資料庫，約佔整體工程的 2–3 成
