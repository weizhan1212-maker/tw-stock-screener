## 一、結論先講

1. **資料抓得到**：證交所的日行情（可回溯到 2022 年）、本益比／殖利率／淨值比、三大法人、融資融券、報酬指數、月營收、季損益，都已確認 API 正常、欄位齊全
2. **財報歷史 8 年可以免費回補**：用 FinMind 免費方案。限制是一次只能查一檔、每小時 600 次，回補全部股票約需 17 小時，屬於一次性作業，分 3–4 次跑完
3. **每月成本預估 NT$0**：Vercel、Supabase、GitHub Actions 的免費額度都夠用
4. **GitHub Actions 實測全數通過**：證交所、櫃買中心（含 2022 年歷史）、FinMind 都抓得到，每 3 秒一次的頻率沒有被擋（詳見第五節）
5. **唯一意外**：FinMind 的「還原股價」免費版不能用 → 改成**自己計算還原股價**（用證交所除權息資料、櫃買的「次日參考價」），不影響成本

## 四、根據 PoC 調整的決策

| 項目 | 原規劃 | 調整後 | 理由 |
|---|---|---|---|
| 月營收、財報、股利的每期更新 | 公開資訊觀測站 | 證交所／櫃買 OpenAPI（一次拿全部公司最新一期） | MOPS 禁止自動抓取；OpenAPI 是官方開放、合規 |
| 財報歷史回補 | MOPS 或 FinMind（待定） | FinMind 免費方案，一次性回補 | 免費、資料齊全，額度足以分次跑完 |
| 回測價格矩陣 | 單一檔案 | 依年份分檔 | 省傳輸量，降低超出 Supabase 免費額度的風險 |
| 還原股價 | FinMind 現成資料 | 自行計算：證交所 `TWT49U` 除權息資料；櫃買用行情裡的「次日參考價」 | FinMind 還原股價免費版不開放（實測） |
| 櫃買日行情 | 新舊網站皆可 | 只用新版網站 | 舊版會忽略日期參數（實測） |
