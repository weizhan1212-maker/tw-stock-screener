- **決策授權**：未定義的細節由 Claude 以「**專業投資者＋一般投資者**」雙重視角自行決定，事後記錄在本文件第 4 節。**涉及費用、法規、資料授權的決定，一律先問 Willy**
- **判斷原則**：正確性 > 簡單好維護 > 功能豐富
- **回應風格**：精簡、直接、可執行；不確定就問，有多種解讀時列出來

## 5. 技術架構概要

```
[證交所／櫃買／公開資訊觀測站]
        │  每個交易日 18:43、23:27（GitHub Actions + Python）
        ▼
[抓取 → 清洗 → 計算指標 → 產出資料檔]
        │  最新快照、月底快照、個股歷史
        ▼
[物件儲存（需登入才能讀）]  ←→  [Supabase：Google 登入、白名單、策略、自選股、回測紀錄]
        │
        ▼
[Next.js 網站（Vercel）] → 使用者瀏覽器內執行篩選與回測（Web Worker）
```

## 9. 名詞速查

| 名詞 | 意思 |
|---|---|
| 盤後 | 收盤後才更新的資料，非即時 |
| 還原股價 | 把除權息、減資的影響補回去的股價，讓長期報酬計算正確 |
| 前視偏誤 | 回測時用到「當時還不知道」的資料（例如財報還沒公布就拿來選股），會讓績效虛胖 |
| 倖存者偏差 | 回測只用現在還活著的股票，忽略已下市的股票，會讓績效虛胖 |
| 報酬指數 | 含股利再投入的大盤指數，比一般加權指數更適合當比較基準 |
| 量比 | 當日成交量 ÷ 20 日平均成交量 |
| MDD | 最大回撤：從最高點跌到最低點的最大跌幅 |
| CAGR | 年化報酬率 |
